### 2. PyAutoGUI Automation – YouTube Video Launcher
An automation script developed using PyAutoGUI that:
- Opens Google Chrome
- Navigates to YouTube
- Searches for "Moral Stories"
- Plays the first video from the results

---

### 3. Playwright Automation – YouTube Video Launcher
An automation script developed using Playwright that performs the same task as PyAutoGUI:
- Opens YouTube via browser automation
- Searches for "Moral Stories"
- Plays the first video

**Note:**  
Both PyAutoGUI and Playwright were used for the same task to understand the difference in approach between GUI-based automation and browser automation frameworks.

---

### 4. Streamlit Application – Environment Quiz App
A beginner-friendly web application built using Streamlit featuring:
- User name input before starting the quiz
- Personalized welcome message
- 10 multiple-choice questions on the topic of Environment
- Scoring system (10 marks per question)
- Final result display with graded feedback:
  - 1–49: *Its ok. Try better next time*
  - 50–70: *Well tried. Aim for the maximum next time*
  - 71–99: *Super. You almost nailed it*
  - 100: *Congratulations. You grabbed all the points*
- Visual feedback using balloon animations for high scores

### 5. Flask – BMI Calculator App
Learned the basics of Flask, including routing, handling forms, and connecting HTML/CSS with Python.  
Created a basic BMI Calculator web application using Flask to understand frontend and backend integration
